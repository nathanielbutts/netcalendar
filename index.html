About schedule editing

The website loads nets.json (plain UTF-8 JSON) from your GitHub Pages repository. Edits made here are saved in this browser only until you export and commit nets.json to GitHub. Import a file to replace the local schedule. Time is stored in UTC; local entry automatically converts using the browser’s time zone and today’s selected date (DST may change other dates).

Publish updates on GitHub Pages

1. Click Download nets.json after editing.

2. Open your netcalendar GitHub repository.

3. Upload or replace nets.json in the repository root and commit your changes. The public site will use the new schedule after GitHub Pages deploys.

4. Other visitors cannot overwrite your repository merely by using the web editor. Existing browser overrides take priority locally; use Discard browser edits to reload the published file.
